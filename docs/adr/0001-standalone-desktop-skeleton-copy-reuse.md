# 0001 - 桌面骨架工程独立，依赖与 Android 版完全解耦，复用采用单向文件复制

将项目迁移到 Windows/Linux/macOS 时，新建一个独立的骨架工程目录，其构建与依赖和现有 Android 工程（`app/`）完全不共享——不设共享 Gradle 模块、不做多平台抽层。需要复用的 Kotlin 代码（模型目录、导入、调度器等 JVM 可测部分）直接把文件复制过去。

**Consequences**：接受代码重复，两边的同名文件会各自漂移；桌面版独立演进，不承担向移动版回移的义务。
