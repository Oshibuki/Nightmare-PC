# 11: 最小图模型与节点类型

**What to build:** 作为 AI coding agent，桌面侧有一套纯 JVM 的最小图模型与节点类型，只承载工作流的表现语义；三类 txt2img 节点能被创建、连线与序列化，为两种交互模式提供唯一的数据基础。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 图模型以纯 JVM 数据表示节点、连线、端口与位置，不依赖任何 UI 框架
- [ ] 节点类型只含表现成员（端口、标题、宽度、是否显示结果等），不含执行语义
- [ ] 默认覆盖三类节点：提示词、SD 采样器、输出
- [ ] 节点类型与工作流使用 `GLOSSARY.md` 的统一术语
- [ ] JVM 测试覆盖三类节点创建、合法与非法连线、序列化形状
- [ ] 不复制移动版执行与迁移逻辑，不引入视频或 NPU 节点
- [ ] 移动版零改动，符合 ADR-0007
