# 15: 失败、取消与超时的运行态收口

**What to build:** 作为桌面用户，运行失败、我主动取消或超时之后，能看到可读原因；工作流保持可编辑，结果面板不留下半成品，也不会有后台孤儿进程。

**Blocked by:** 14 — 运行——子进程、进度事件与成功产物.

**Status:** ready-for-agent

- [ ] 非零退出码、stderr 报错、超时与缺模型统一转成运行态失败
- [ ] 错误条显示退出码与首行原因，完整信息进入日志
- [ ] 运行中可取消；取消与关闭窗口都结束子进程
- [ ] GUI 侧提供可配置超时（默认十分钟），超时结束子进程并置失败
- [ ] 失败或取消产生的临时产物被删除，结果面板没有半成品
- [ ] 当前工作流保持不变，失败后可直接修改重跑
