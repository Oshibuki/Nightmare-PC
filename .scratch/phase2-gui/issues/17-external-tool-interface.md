# 17: 外部工具驱动接口预留

**What to build:** 作为维护者，工作流能被外部工具用一组明确命令创建和修改，为将来对话模式留出接缝；本工单不实现 LLM、provider 或密钥，也不改变工作流的持久化格式。

**Blocked by:** 16 — 工作流保存、载入与版本校验.

**Status:** ready-for-agent

- [ ] 提供等价的新建工作流、设置参数、添加节点、连线与运行的命令面，作用于同一份工作流
- [ ] 命令面由 GUI 状态与运行态承载，不新增第二套持久化格式
- [ ] 假工具调用能搭出一条可运行的 txt2img 工作流并触发运行
- [ ] 不引入 LLM provider、密钥管理、HTTP 服务或对话界面
- [ ] JVM 测试覆盖工具调用链的成功与被拒绝路径
- [ ] 符合 ADR-0008 中「对话模式后置但预留接口」的约定
