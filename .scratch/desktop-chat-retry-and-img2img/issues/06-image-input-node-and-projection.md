# 06: 图片输入节点与运行器 img2img 投影

**What to build:** 作为维护者，桌面工作流能在节点注册表里表达一个最小的图片输入节点（携带 path/strength、连到采样节点），运行器按工作流里是否存在该节点把工作流投影成文生图或图生图 CLI 子命令——图生图带上 `--init-img`/`--strength`，文生图路径与既有行为完全一致。这是一条可独立演示的纵向切片：搭一条含图片节点的工作流 → 经运行器投影 → 假 CLI 出图。本工单不接对话工具面（那是 07），但把地基与命令面打通。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 节点注册表新增一个最小图片输入节点，携带 path/strength 参数、可连到采样节点；受桌面自持纪律约束（ADR-0007），既有三种节点行为不变
- [ ] 既有工作流 JSON 格式的字符串参数映射可直接承载图片路径，不改格式版本；保存/加载往返不丢图片节点及其参数
- [ ] 运行器按工作流里是否存在图片输入节点决定投影：含则投影图生图子命令并带 `--init-img`/`--strength`（strength 默认 0.75、范围 0..1），不含则仍投影文生图；单运行、单一 CLI 子进程、取消/关窗清进程语义不变（ADR-0009）
- [ ] 假 CLI 端到端断言：含图片节点的工作流投影出正确参数并产出图、不含的工作流行为与既有完全一致；断言按参数名比较、不做字符串全等
- [ ] ADR-0013 的取舍在代码与文档中一致，不引入全局运行参数或直调引擎入口的独立路径
