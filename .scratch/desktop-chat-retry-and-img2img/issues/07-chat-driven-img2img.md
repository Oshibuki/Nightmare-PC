# 07: 对话模式经工具发起图生图

**What to build:** 作为桌面用户，我能在对话里说「用这张图按这句描述重画」并给出本地图片路径，AI 经既有工具面改同一份工作流——新增图片输入节点、把 path/strength 写进参数、连到采样节点、运行——图生图产出的图进入与文生图相同的结果面板，工作流收为顶部面包屑、图以气泡呈现。

**Blocked by:** 05 — 「重发上一句」按钮与可复现重放（它把 Agent 构造抽成工厂，是本工单改 `SYSTEM_PROMPT`/工具面的落点，先落可避免同处冲突）; 06 — 图片输入节点与运行器 img2img 投影

**Status:** ready-for-agent

- [ ] 对话工具面能把「本地图片路径 + 描述」表达为对既有工作流的操作：新增图片输入节点、写入 path/strength（默认 0.75）、连到采样节点、运行；strength 由 AI 经工具参数设置，首切片不做用户侧控件或专门的 Ask 追问
- [ ] Agent 的系统提示教会模型新节点的类型、参数与连线端口，使一句话能驱动一条可运行的图生图工作流；工具结果形状与既有五条命令一致
- [ ] 生成的图按既有监听/快照路径进入结果面板、以 Picture 气泡呈现；运行日志仍走既有日志面板、不进气泡、不改运行态通知链
- [ ] 假 ChatModel + 假 CLI 的状态层测试跑通「一句话 → 工具改工作流 → 图生图 → Picture 气泡 + 结果快照」全链路；断言按字段名比较
- [ ] 含图片节点的工作流不改既有文生图对话行为；切模式/取消/追问等生命周期语义沿用既有实现，不为图生图开特例
