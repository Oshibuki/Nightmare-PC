# 05: 「重发上一句」按钮与可复现重放

**What to build:** 作为桌面用户，我能在输入框旁点一个「重发上一句」按钮，把上一条已发出的用户消息当作新消息再发、起新回合；每次重放都从干净的工作流与 agent 上下文开始，让我改了配置或提示词后能用同一句反复验证、得到可比的结果，而旧气泡与已生成的图都保留。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 对话模式输入框旁新增单一「重发上一句」按钮，不在错误/取消/用户气泡上分设；仅当存在上一条已发出的用户消息时可用；tooltip 显示该句被截断的文本
- [ ] 点击后取上一条用户消息文本当新消息发、起新回合；输入框草稿不参与；UI 对话气泡照常追加、既有气泡与产物图保留
- [ ] 重放前用既有「新建工作流」命令复位工作流，并用干净 agent 上下文起回合；同一句重放两次得到一致的工作流与产物
- [ ] 干净上下文只重建 Agent 实例以清掉其累积 history，复用同一个注入的 ChatModel；provider 配置由既有 `settings.resolved()` 动态读取，不重新接线或重建 model——把 Agent 构造抽成工厂供重放调用（该工厂也是后续对话工具面改 `SYSTEM_PROMPT` 的落点）
- [ ] 运行中按钮禁用并提示「运行中」，二次重发被拒且不丢已输入文字；追问等待期间点按钮等同发送新指令——先以 CANCEL 放行等待中的追问再起新回合，不新增特例
- [ ] 「失败/取消后重试保留上下文」的既有路径语义不变，与「重发上一句」互不干扰；两条路径各有状态层断言
- [ ] 既有测试不回归，新增断言只覆盖外部可见行为（复位、上下文干净、气泡追加、并发拒绝、追问放行）
