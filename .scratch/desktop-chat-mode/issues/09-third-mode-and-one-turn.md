# 09: 第三条对话模式与一条对话回合

**What to build:** 作为桌面用户，我能在默认/高级之外看到一个对话模式入口；输入一句自然语言后，看到 AI 的回复、工具调用摘要和生成的图以气泡出现，工作流收为顶部面包屑，生成的图进入结果面板——一条从对话到出图的完整路径。

**Blocked by:** 08 — 落地 agent 核心与假对象底座

**Status:** ready-for-agent
