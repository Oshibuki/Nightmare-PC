# 12: 回合生命周期——取消、并发、切模式、重试

**What to build:** 作为桌面用户，我在出图运行中切到默认/高级模式后台仍继续、点取消在当前工具收尾后停下并保留已出的图、失败后重试保留对话上下文——回合的整个生命周期行为一致且不破坏既有的单运行/关窗清进程纪律。本工单拥有**唯一的取消/关窗入口**，统一编排回合标志、追问放行（调用 11 提供的原语）与进程清理。

**Blocked by:** 09 — 第三条对话模式与一条对话回合; 11 — 结构化追问（Ask）的放行与回写

**Status:** ready-for-agent

- [ ] **唯一取消/关窗入口**：点取消或关窗时统一编排——置回合取消标志、调用 11 提供的追问 CANCEL 放行原语、关窗时清 CLI 子进程；取消为协作式：等当前工具调用收尾、下一轮首真正停，不发新 LLM 请求、不硬中断线程；取消气泡标「已取消」、保留已产出图与历史
- [ ] 回合运行期间发送按钮禁用并提示「运行中」，不排队、不丢已输入的文字
- [ ] 切模式只切外壳、后台回合继续、结果仍入同一份工作流；关窗沿用既有清进程路径（ADR-0009）
- [ ] 失败/取消后允许重试：以新用户消息追加历史、起新回合，不抹掉旧气泡；对话历史只在内存，切换保留、重启清空
- [ ] 不修改既有运行器的单运行/可取消/关窗清进程语义
